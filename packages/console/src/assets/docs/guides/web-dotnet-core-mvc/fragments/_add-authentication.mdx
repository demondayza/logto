Open `Startup.cs` (or `Program.cs`) and add the following code to register MyEyesID authentication middleware:

<Code title="Program.cs" className="language-csharp">
{`using MyEyesID.AspNetCore.Authentication;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddMyEyesIDAuthentication(options =>
{
  options.Endpoint = "${props.endpoint}";
  options.AppId = "${props.app.id}";
  options.AppSecret = "${props.secrets[0]?.value ?? props.app.secret}";
});

app.UseAuthentication();`}
</Code>

<br/>

<CustomDomainEndpointNotice />

The `AddMyEyesIDAuthentication` method will do the following things:

- Set the default authentication scheme to `MyEyesIDDefaults.CookieScheme`.
- Set the default challenge scheme to `MyEyesIDDefaults.AuthenticationScheme`.
- Set the default sign-out scheme to `MyEyesIDDefaults.AuthenticationScheme`.
- Add cookie and OpenID Connect authentication handlers to the authentication scheme.
