# MyEyesID awesome

Here's the list of awesome community-contributed resources for MyEyesID. Feel free to add yours by submitting a pull request.

## Account

- [MyEyesID Account Dashboard](https://github.com/t2vee/MyEyesID-Account-Dashboard) by @t2vee

## API

- [Go API client for myeyesid](https://github.com/mostafa/go-api-client) by @mostafa

## CLI

- [MyEyesID provisioning](https://github.com/LBF38/myeyesid_provisioning) by @LBF38

  MyEyesID provisioning is a CLI tool for bulk management and provisioning of RBAC roles, applications and organizations.

- [MyEyesID admin creator](https://github.com/appthrust/myeyesid-admin-creator) by @suin

  A script to help provision MyEyesID by automatically creating an admin account and configuring initial settings.
